# Calculadora em Python

Projeto de uma calculadora desenvolvida em Python para realizar as quatro operações matemáticas básicas.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Tratamento de entradas inválidas
- Tratamento de divisão por zero

## Tecnologias utilizadas

- Python

## Objetivo

Projeto desenvolvido com o objetivo de praticar conceitos fundamentais de Python, como funções, estruturas condicionais e tratamento de exceções.
